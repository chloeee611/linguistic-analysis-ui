# Linguistic Analysis UI

A web-based user interface for linguistic analysis built with React, TypeScript and Vite.

This project provides interactive visualisations and dashboards for linguistic data using Ant Design (antd) and Recharts.

### Key technologies

- React 19 + TypeScript
- Vite for fast development and bundling
- Ant Design (antd) for UI components
- Recharts for data visualisation
- Axios for HTTP requests

## Quick start

### Prerequisites

- Node.js (18+ recommended)
- npm (or use yarn/pnpm if preferred)

### Install

1. Install dependencies

    `npm install`

2. Start the development server (HMR)

    `npm run dev`

3. Open the app in your browser

    _By default Vite serves at http://localhost:5173 - open that URL after starting the dev server._

### Repository structure (selected files)

- **package.json** - project metadata and scripts
- **vite.config.ts** - Vite configuration
- **index.html** - app entry HTML
- **src/** - application source code
- **.env** - environment variables (if used)
